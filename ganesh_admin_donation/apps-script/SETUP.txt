GOOGLE SHEET / APPS SCRIPT SETUP

1. Create a Google Sheet in your Google Drive.
2. Copy the Sheet ID from the URL:
   https://docs.google.com/spreadsheets/d/THIS_PART_IS_THE_ID/edit
3. In the Sheet, create a tab named Donations. If you don't, the script will create it.
4. Open Extensions > Apps Script.
5. Paste Code.gs into the Apps Script editor.
6. Open Project Settings > Script Properties and add:
   ADMIN_USERNAME = your admin username
   ADMIN_PASSWORD = a strong admin password
   SHEET_ID = your Google Sheet ID
7. Save.
8. Deploy > New deployment > Web app.
9. Execute as: Me.
10. Who has access: Anyone.
11. Deploy and copy the Web app /exec URL.
12. In admin-donation.js replace:
   PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE
   with your /exec URL.
13. Upload admin-donation.html, admin-donation.css, admin-donation.js and assets/vinayaka-watermark.png to your GitHub Pages site.

IMPORTANT SECURITY:
- Never put ADMIN_USERNAME, ADMIN_PASSWORD or SHEET_ID in GitHub code.
- The Google Sheet should NOT be shared publicly.
- Only give Sheet access to the committee admins who need it.
- The browser only sees the Apps Script Web App URL, not the Script Properties.
- For stronger production security, Google account based admin access is preferable to a shared password.
