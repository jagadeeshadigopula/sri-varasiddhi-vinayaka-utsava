# Sri Varasiddhi Vinayaka Utsava Committee 2026

A responsive Ganesh Utsav website that can be tested locally in VS Code and hosted on GitHub Pages.

## Project structure

```text
Sri_Varasiddhi_Vinayaka_Utsava_2026/
│
├── index.html
├── style.css
├── script.js
├── README.md
│
└── assets/
    ├── ganesh-poster.jpg
    └── ganesha-pancharatnam-instrumental.mp3
```

## Run in VS Code

1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Add your own `ganesh-poster.jpg` to the `assets` folder.
4. Add a legally obtained/licensed `ganesha-pancharatnam-instrumental.mp3` to the `assets` folder.
5. Open `index.html`.

Recommended:
- Install the VS Code extension "Live Server".
- Right-click `index.html`.
- Select "Open with Live Server".

## Important

Browsers normally block automatic audio playback. The website therefore has a "Play Music" button. The visitor clicks the button to start the music.

## Customize

Update these placeholders in `index.html`:

- President name
- Vice President name
- Secretary name
- Treasurer name
- UPI ID
- Committee phone number
- Email address
- Pandal address
- Google Maps link
- Event dates and timings
- Sponsor names
- Gallery photos

## GitHub Pages

This is a static HTML/CSS/JavaScript website, so it can be hosted directly using GitHub Pages.

No Python server or database is required.
